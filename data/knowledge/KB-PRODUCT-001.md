# 智云工单平台产品说明

## 产品定位

智云工单平台用于管理企业内部 IT 服务请求，帮助员工提交问题，并由 IT 服务团队统一受理、跟踪和处理。平台覆盖工单从创建到关闭的完整生命周期，适用于账号访问、办公软件、终端设备和内部系统等常见 IT 支持场景。

当前产品版本为 3.2。文档头部的 `document_version` 表示本文档自身的版本，不代表产品版本。

## 工单优先级

平台将工单优先级分为 P1、P2 和 P3：

- P1：紧急故障，例如核心业务系统不可用或故障影响大量员工。
- P2：重要问题，例如部分功能不可用，但仍有替代方案可以继续工作。
- P3：一般问题，例如使用咨询、个人配置问题或不影响正常工作的功能需求。

员工提交工单时可以选择优先级，IT 服务人员也可以根据实际影响范围进行调整。

## 首次响应时限

不同优先级对应的首次响应时间如下：

- P1 工单：15 分钟内首次响应。
- P2 工单：2 小时内首次响应。
- P3 工单：1 个工作日内首次响应。

首次响应时间从工单成功提交后开始计算。首次响应表示 IT 服务人员已经受理并开始跟进，不等同于问题最终解决时间。

## 核心功能

平台支持工单创建、分派、升级、评论和关闭：

- 创建：员工填写问题描述、优先级等信息并提交工单。
- 分派：工单可以分派给对应的 IT 服务人员或处理组。
- 升级：问题影响扩大或处理超时时，可以提升工单优先级。
- 评论：员工和处理人员可以在工单中补充信息、沟通进度。
- 关闭：问题处理完成并确认后，工单进入关闭状态。

## 支持渠道

智云工单平台支持 Web 端和企业微信。两个渠道使用同一套工单数据，员工可以在任一渠道查看处理状态。

当前版本不支持通过个人邮箱或电话直接创建工单；通过这些渠道收到的问题，需要由 IT 服务人员补录到平台中。
